# Blessings Chuulu - Portfolio Website

![Portfolio Preview](https://picsum.photos/seed/portfolio-preview/1200x600.jpg)

A modern, responsive portfolio website for Blessings Chuulu - Computer Networks Engineer and Full Stack Developer from Kabwe, Zambia.

## 🌟 Features

- **Multi-language Support** (English, French, Spanish)
- **Dark/Light Mode Toggle**
- **Responsive Design** (Mobile-first approach)
- **3D Animations & Interactive Elements**
- **Accessibility Features** (High contrast, Large text)
- **PWA Ready** (Progressive Web App)
- **SEO Optimized**
- **Fast Loading** (Optimized performance)

## 🎨 Design Highlights

- **Modern UI/UX** with smooth animations
- **Blue Color Scheme** with professional gradients
- **Interactive Timeline** with beautiful blue shades
- **Project Portfolio** with filtering capabilities
- **Contact Form** with QR code integration
- **Social Media Integration**

## 🛠 Technologies Used

- **HTML5** (Semantic markup)
- **CSS3** (Custom properties, Grid, Flexbox, Animations)
- **JavaScript** (ES6+, Intersection Observer, LocalStorage)
- **Font Awesome** Icons
- **Google Maps** Integration
- **PWA** Features

## 📱 Sections

1. **Hero** - Introduction with typing animation
2. **About** - Personal information and background
3. **Timeline** - Career journey with blue gradient cards
4. **Skills** - Technical skills with progress bars
5. **Projects** - Portfolio projects with filtering
6. **Blog** - Articles and writings
7. **Testimonials** - Client and colleague feedback
8. **Certifications** - Professional certifications
9. **Hobbies** - Personal interests
10. **Contact** - Contact form and information

## 🎯 Timeline Design

The timeline features a beautiful blue gradient progression:

- **2025**: Deep Blue (#1e3a8a to #3b82f6)
- **2024**: Royal Blue (#2563eb to #60a5fa)
- **2023**: Bright Blue (#3b82f6 to #93c5fd)
- **2022**: Light Blue (#60a5fa to #bfdbfe)
- **2021**: Pale Blue (#93c5fd to #dbeafe)
